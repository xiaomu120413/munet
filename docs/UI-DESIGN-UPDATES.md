# UI设计补充决定

本文件记录冻结设计归档之后的用户修正，实施时优先于v1.0规范中相冲突的条目；原始规范与ZIP保留作为历史，不覆盖归档。

## 2026-10-22：窄窗与大字号文字完整显示

页头按实际可用宽度和系统字号决定标题／操作是否上下排列，避免标题被按钮挤断。记录页分段按钮在空间不足时上下排列，完整显示“扫描记录／设备档案”，不依赖省略号辨认功能。普通宽度仍保持横排，按钮沿用原生按下、聚焦和选中状态。实机证据见[阶段7](ui-verification/phase7/README.md)。

## 2026-10-22：关于页精简与PC窗口按钮避让

按用户要求删除关于页“隐私说明”整段及未使用的隐私政策占位文案。版本、应用标识、使用说明和默认折叠的Debug诊断保留。PC隐藏系统标题栏后仍显示系统窗口按钮，右侧内容顶部留40vp避让，防止刷新／导出／更多被按钮覆盖；不新增自绘标题栏。六档六页实机对照见[阶段6报告](ui-verification/phase6/README.md)。

## 2026-10-22：PC采用左右分栏

用户指出PC应为分栏，而非顶部导航。此前实现将分栏仅用于内容区，仍使用六项顶栏，未符合用户预期；本次改为：

- PC宽窗口（≥840vp）：左侧192vp导航，右侧业务内容。六个页面从左侧直接进入。
- PC窄窗口（<840vp）：左侧收紧为72vp的图标＋文字导航栏，右侧内容使用剩余宽度；不回退到顶部横向导航，不使用手机工具中间页。
- 导航独立纵向滚动，短窗口仍能访问底部入口；原生按钮提供鼠标、按下、聚焦和选中状态。
- 页面内部按扣除左栏后的实际宽度决定单列／双列／宽表，大字体继续提前回退单列。
- 手机和平板现有导航断点保持；切换PC窗口宽度不重建业务ViewModel，不重置任务和参数。
- 系统窗口装饰仍由系统管理，不新增自绘标题栏。

旧阶段5截图、顶部滚轮修复和PC顶栏说明均属于修正前的历史记录，不能代表本次左右分栏效果。桌面验收脚本已更新：逐档断言导航位于左侧，并核对72／192vp宽度。PC仍被其他任务占用期间，只做本地构建，不抢占设备或以旧截图冒充新界面。
