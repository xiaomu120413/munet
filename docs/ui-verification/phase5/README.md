## 已确认

- 电脑使用六项顶部导航，系统管理窗口装饰；首页宽窗网络与Wi-Fi双列显示。
- 真机允许应用内容宽320vp，测试实测320.000004vp、内容高620.000008vp，densityPixels约1.9；浮点误差不表示额外宽度。
- 320vp下本机网络、Ping、端口和局域网的正文已查看，目标输入和按钮没有横向遮挡，长说明换行。四张 `pc-320-page-*-before.png` 是追加鼠标滚轮修复前的截图，只裁取木络窗口。
- 窄窗顶栏可以触屏横向滑动，Tab聚焦时也会自动滚动到目标。普通鼠标滚轮原先不能横向带动顶栏；隐藏的滚动条使鼠标用户难以发现后面的导航。
