# NetTools UI 重新设计归档

日期：2026-10-22 · 版本：1.0 · 状态：设计评审稿，待实现。

本次归档包含六个主页面、设备档案子页和窄窗口工具入口。统一取消自绘桌面标题栏，重新设计鸿蒙控件、点击反馈及手机、平板和电脑布局。**此归档不表示应用代码已实现这些设计，也不表示完成真机验收。**

- [完整设计规范](UI-SPEC.md)：信息架构、逐页布局、组件状态、弹层、适配和验收条件。
- [设计图册](GALLERY.md)：8 张手机／平板对照图及电脑参考图。
- `assets/`：本地设计图，无外部图片依赖。
- `generation-prompts.json`：本次图稿的生成提示词。
- `manifest.json`：文件清单、大小与 SHA-256 校验值。

阅读顺序：先看图册，再以设计规范确定行为与尺寸。生成图片是视觉参考；出现箭头、字体、行高、示例数据或文案偏差时，以规范为准，具体校正项见规范末尾。

本次只归档设计文档。没有归档聊天，没有新增安装包，没有修改应用业务代码。此前已有的工作区代码改动保留。
