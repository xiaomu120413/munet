# 木络 MuNet 全界面设计规范

2026-10-22 · v1.0 · 设计归档／待实现

## 1. 设计目标和边界

以鸿蒙原生网络诊断工具为目标，优先可读、可操作和数据准确。取消重复品牌横幅、自绘桌面标题栏、巨型 IP、装饰性指标卡片和每行独立浮动卡片。用分组、留白、细分隔线组织内容；圆角用于系统控件及必要分组，不用阴影堆层级。

保留真实能力：本机网络、TCP Ping、TCP connect 端口扫描、局域网设备发现、扫描历史、设备档案、导出、再次扫描和关于。没有新增流量图、MAC／厂商列、系统完整监听表、设备详情、账号或云服务。

六个主页面 + 设备档案子页 + 手机／窄窗口工具入口都在本规范范围内。系统文件选择器沿用平台，不自绘。

本规范参考 [HarmonyOS 设计指南](https://developer.huawei.com/consumer/cn/design/)、[多设备开发最佳实践](https://developer.huawei.com/consumer/cn/best-practices/multidevice/) 和 [ArkUI Button](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/ts-basic-components-button)。下列断点、字号、间距和动画约束是**本项目设计值**，不是声称官方必须采用的固定数字。系统资源值和控件形态应以目标 SDK 实际支持版本为准。

## 2. 信息架构和导航

### 手机和可用宽度小于 840vp 的触屏窗口

底部四个图标加文字入口：网络、工具、记录、更多。

- 网络：直接显示本机网络页。
- 工具：显示 Ping、端口扫描、局域网三行入口；进入工具后显示“返回工具”，底栏仍选中工具。
- 记录：扫描记录／设备档案分段选择；切换保留各自位置。
- 更多：直接显示关于内容，不增加空的中间菜单页。

返回顺序：先关闭菜单／操作面板，再处理子工具返回。工具运行时返回工具列表需先提示“停止当前任务并返回？”；取消则继续，确认才取消任务。不得静默丢弃结果。

### 平板宽窗口

可用宽度至少 840vp 时使用 184–200vp 侧栏，直接列出本机网络、Ping、端口扫描、局域网、记录、关于。选择态为浅强调底＋强调文字／图标；侧栏不显示版本和自检。页面宽度按扣除侧栏后的实际内容宽度计算。

### 电脑

宽窗口使用六项顶部应用导航，内容沿用平板宽屏规则。不绘制应用图标＋MuNet 的独立标题横条，不绘制最小化／最大化／关闭按钮。系统窗口装饰由系统管理；不要把系统装饰画进应用内容。电脑窗口不足 840vp 时导航保持可访问的滚动顶栏，内容退化为窄布局，不能强行保留大表格。电脑与触屏平板导航形态由运行平台决定，不因偶尔接入鼠标而反复切换。

页面名称属于内容区，不等于被取消的桌面窗口标题栏。

## 3. 尺寸与响应式布局

| 可用窗口宽度 | 触屏导航 | 内容排布 |
|---|---|---|
| <600vp | 四项底栏 | 单列，边距16vp，多行结果列表 |
| 600–839vp | 四项底栏 | 边距24vp；空间足够的参数可成对排列；结果默认多行列表 |
| ≥840vp | 侧栏 | 扣除侧栏后内容至少720vp才启用双列或完整表格，否则继续单列 |

参考画布：手机390×844，平板竖屏834×1194，平板横屏1194×834，电脑1440×1024。逻辑尺寸为布局参考，实际按窗口测量，不通过机型名称锁死布局。

834vp 平板竖屏默认窄导航和单列；1194vp 横屏使用侧栏。平板横向分屏到600vp时使用窄窗口规则。大字体导致列宽不足时，比断点更早切换单列；不缩小字体硬塞表格。屏幕宽但高度不足时允许内容滚动，不能裁掉开始／停止或确认按钮。

底部操作和导航避让系统手势区；顶部避让状态栏／系统安全区。软键盘弹起时目标输入和开始操作必须能滚动进入可见区。不得对内容整体缩放。

调整窗口、横竖屏切换仅改变布局，不重建业务任务，不重置参数、筛选、结果、选中子页或滚动位置。跨主页面离开正在运行的工具按前述取消确认处理；该行为需要后续实现中核对 ViewModel 生命周期。

## 4. 视觉与控件基础

| 项目 | 设计值／规则 |
|---|---|
| 字体 | 系统中文字体；正文16fp、辅助14fp、页名24fp中等字重；跟随系统字体缩放 |
| 数值 | IP、端口等可用系统等宽字体；行高不因字体切换而挤压 |
| 间距 | 4/8/12/16/24/32vp；组间24vp，标题到内容12vp |
| 点击区 | 至少44×44vp；工具入口和触屏列表基准56vp，文字增多自动增高 |
| 图标 | 系统符号资源，常规20–24vp；图标按钮具备无障碍名称 |
| 色彩 | 优先系统语义颜色；强调色表示操作／选中，正文与次级文字保持可读对比 |
| 分隔 | 细水平分隔线；宽屏表格默认不画竖网格线 |
| 分组 | 连续信息面，必要分组8–12vp圆角；不每条记录独立投影 |
| 输入 | 有明确标签；占位文字不是唯一标签；错误说明紧贴字段 |
| 控件 | 原生 Button、Select、Toggle、Tabs／分段控件、Menu、Dialog 等，版本不足时用 SDK 支持的同语义组件 |

深色模式随系统：背景、分组底、文字、分隔、禁用态分别使用语义资源，不把白底和浅灰字固定写死。强调、成功、错误均要有文字含义，不能只靠颜色。深色图稿不在本轮图册中，实施时必须单独验收。

### 点击、悬停和焦点

| 状态 | 按钮／图标操作 | 导航／列表 |
|---|---|---|
| 常态 | 主操作强调底；次操作浅底；文字操作强调文字 | 文字清楚，非交互信息不伪装成按钮 |
| 悬停 | 系统悬停底色；必要时提示图标含义 | 只对可操作区域提供悬停底；普通结果行不暗示可跳详情 |
| 按下 | 开启原生状态效果；局部压暗／高亮，松开恢复 | 可交互行出现局部按下反馈，不把按下误当持续选中 |
| 聚焦 | 系统焦点框，键盘可到达 | Tab顺序与视觉顺序一致，Enter／Space触发操作 |
| 选中 | 分段／导航持续选中，与按下独立 | 图标、文字及浅底共同表达，不仅改变颜色 |
| 禁用 | 系统禁用色，不能触发；附近说明原因 | 不能用禁用隐藏任务状态 |
| 忙碌 | 同一任务不能重复启动；开始切为停止 | 进度变化不强行抢焦点、不逐条播报噪声 |

使用系统默认动画和减弱动态效果设置，不另造弹跳缩放。复制成功用轻提示“已复制”，失败用“复制失败，请重试”；不把复制内容整串塞进提示遮住页面。

## 5. 逐页设计

### 5.1 本机网络

图稿：[01](assets/01-local-network.png)。标题本机网络，唯一页面操作刷新。当前连接简明显示连接类型、接口、连接状态和主地址；不再独立做巨型 IP 卡。

网络参数包括地址／前缀、网关、DNS、MTU、搜索域（有值时）、IPv4／IPv6 可用性；多个网络按系统实际数据分组，默认网络优先。Wi-Fi 仅在能读取到对应信息时显示 SSID、信号、频段／频率、速率。全部网卡显示接口、协议、地址、回环／未启用信息，不把“接口有地址”说成“互联网可达”。

手机：连接→网络参数→Wi-Fi→全部网卡顺序单列。长 IPv6 和 DNS 换行；明确复制按钮点击区44vp。平板／电脑：参数和Wi-Fi双列，下方全部网卡表；没有Wi-Fi时参数扩展，不留空白占位列。

刷新期间保留旧数据并标识正在刷新；首次进入可显示读取指示。离线显示“当前无默认网络连接”，已读出的回环等接口仍展示。局部Wi-Fi读取失败不应清空其他网络信息。实现函数名、netId、自检按钮不出现在首页。静态连接信息和网卡行没有详情跳转箭头。

### 5.2 Ping

图稿：[02](assets/02-ping.png)。保留 TCP 探测语义。目标支持 IP／域名；端口可选80、443、22、3389、8080；智能回退按现有443→80→22→8080→3389顺序尝试；次数1／4／10及持续模式。

智能回退开启时，单端口控件置为不适用并显示“自动回退”，不能一边显示固定443生效一边执行回退。持续模式开启时次数不适用，保留退出持续模式前所选值。运行中参数只读，“开始”切为“停止”。

手机：参数单列；摘要允许两行以上；每条结果第一行序号、成功／拒绝／超时、耗时，第二行实际端口和时间。不把五列压进一行，不把统计缩成小字。平板／电脑：参数横排，结果表含序号、结果、耗时、实际端口、时间。

摘要显示发送、接收、丢失比例和平均／最小／最大耗时。没有成功结果时耗时统计显示“—”，不能显示虚假的0ms。空态“输入目标后开始TCP探测”；错误说明保留输入和结果。始终提供“TCP探测；端口关闭或防火墙拦截不代表主机离线”的简短说明。

### 5.3 端口扫描

图稿：[03](assets/03-port-scan.png)。目标输入、扫描本机开关、常用／Web／1–1024／自定义范围；自定义时才显示表达式输入。端口总数由实际解析结果提供，不把图中的24写成常量。并发32／64／128／256，超时800／1500／3000ms。

手机把并发与超时折叠进扫描设置，折叠行仍显示当前值；选择自定义后表达式即时可见。平板／电脑展开设置并横排。自定义校验错误紧贴表达式，保留文本，不启动任务。

扫描本机模式明确探测127.0.0.1、::1及本机IPv4，保留远程目标以便切回。它是connect探测，不是读取系统完整监听表。远程结果标“开放”，本机结果标“占用”；服务名为端口常见用途，不是服务指纹识别。

手机结果用两行条目：端口＋服务，状态＋耗时；若四列在大字体下仍够宽才可保持简表。平板／电脑表格端口／状态／服务／耗时。运行时进度＋已探测数；停止后显示“已停止”，保留部分结果。大范围确认仍使用现有4096次探测阈值，次数按真实预期探测数计算。

### 5.4 局域网

图稿：[04](assets/04-lan.png)。输入CIDR，自动推导当前网段并允许修改。主机数按CIDR实际可探测主机数显示。只有“开始发现／停止”一个主操作，超过现有1024台阈值时确认范围和预计耗时不确定性。

手机结果每台设备多行：IP、主机名、开放端口；端口多时换行，不挤到IP右边。平板／电脑表格IP／开放端口／主机名。mDNS未发现名字显示“—”，不能根据猜测填厂商或设备类型。图中“网关”等均为示例，不表示已经识别到该名称。

保留AP隔离提示。未发现显示“未发现在线设备。请检查网段；AP隔离也可能影响发现。”停止后保留已发现设备并标明部分结果。设备行没有详情或再扫入口。

### 5.5 扫描记录

图稿：[05](assets/05-history.png)，电脑补充参考[09](assets/09-desktop-history.png)。局部分段扫描记录／设备档案；类型筛选全部／Ping／端口扫描／局域网。顶部刷新和更多，宽屏另有导出按钮。时间倒序。

手机记录每条三部分：目标与类型、结果摘要、时间与再扫；仅“再扫”触发该条业务操作，整行无详情跳转。宽屏完整表格：时间／类型／目标／摘要／操作。摘要和目标可换行，不截掉关键结果，日期可压成月日但详情文档中不暗示新增详情页。

手机更多面板：导出CSV、导出JSON、清空全部。平板／电脑导出为锚定菜单，清空在更多菜单。选择格式后调用系统文件保存器；取消不报成功，失败给出可重试提示，成功才显示“已导出”。保持现有导出语义：导出全部扫描记录；筛选只影响展示。界面菜单下说明“导出全部扫描记录”，不要把筛选后的可见条数误当导出范围。

再扫：进入对应工具、回填目标，不自动启动网络探测。加载／错误保留筛选。无记录文案“暂无记录，扫描完成后会出现在这里”。筛选无匹配文案“该类型暂无记录”，同时保留其他筛选入口。

### 5.6 设备档案

图稿：[06](assets/06-device-archive.png)。保留记录页分段、刷新和更多；隐藏扫描类型筛选和导出。只展示IP、主机名、已发现端口、最近发现时间。名称未知用“—”。

手机按多行条目显示；平板／电脑四列表格。不能暗示实时在线，最近发现时间不等于最近在线时间。没有再扫、重命名、设备详情或单设备删除。空态“暂无设备档案，完成局域网发现后会出现在这里”。

清空目前是扫描记录和设备档案一起清空；两处菜单都必须叫“清空全部记录与档案”，确认弹窗明确这一范围，不能误称仅清空当前子页。

### 5.7 关于／更多

图稿：[07](assets/07-about.png)。手机底部更多直接显示本页，页面名称更多；宽屏叫关于。内容为名称、简短说明、应用版本、原生核心版本、包名、隐私政策、使用声明。版本来自运行构建，不硬编码图中版本。

各端均单列阅读，宽屏文字内容最大宽度840vp，正文行长约45–65个字符；不为铺满大屏而无限拉长分隔和值的距离。暂无有效隐私政策URL时显示待补充说明，**没有跳转箭头和点击态**，不伪造链接。

开发诊断仅Debug构建可见，默认折叠。展开后说明仅用于开发排查，显示“运行原生探测自检”和执行结果。Release中整个入口不可见。无刷新、导出或额外更多菜单。

### 5.8 工具入口

图稿：[08](assets/08-tools.png)。只在手机／窄触屏窗口使用，三条真实导航入口：Ping／TCP连通性探测、端口扫描／探测开放端口或本机占用端口、局域网／发现当前网段的设备。

每行图标、名称、说明、右箭头，整行可按；图标分别使用连通性波形、端口／列表、网络节点的系统符号。宽平板和电脑直接由导航进入三个工具，不额外绕工具首页。图中Ping出现房屋图标属于图稿偏差，实施时必须改为连通性图标。

## 6. 弹层与特殊状态

| 场景 | 手机 | 平板／电脑 | 行为 |
|---|---|---|---|
| 类型、端口等选择 | 系统选择面板／SDK支持控件 | 就近选择菜单 | 选中立即更新，不另加无意义确认 |
| 导出菜单 | 底部操作面板 | 按钮锚定菜单 | 格式后进入系统保存器，取消不改数据 |
| 清空全部 | 系统确认弹窗 | 系统确认弹窗，宽度受限 | 标题清空全部记录与档案；说明不可恢复；取消／清空，取消为安全初始焦点 |
| 大范围扫描 | 系统确认弹窗 | 居中系统确认弹窗 | 显示实际探测次数／主机数，取消／开始 |
| 自定义校验错误 | 字段下方说明 | 同手机 | 不启动、不擦除输入、不只用Toast |
| 运行错误 | 可关闭的局部错误条 | 同手机 | 保留输入及有效部分结果，提供重试入口 |
| 首次加载 | 内容区进度／简洁读取说明 | 同手机 | 无装饰插画；刷新不遮掉旧结果 |
| 空结果 | 标题＋简短原因及当前动作 | 同手机 | 区分未开始、无结果、筛选无匹配 |
| 任务停止 | 已停止＋完成数量＋部分结果 | 同手机 | 不能标记扫描完成或100% |
| 复制成功／失败 | 系统轻提示 | 同手机 | 反馈局部，读屏可获知状态 |

手机操作面板和大字体弹窗内可滚动，不能让底部确认按钮落到屏幕外。ESC／返回先关闭非破坏性菜单，焦点回到触发按钮；外部点按取消菜单，不执行清空。

## 7. 图稿校正与可信边界

生成工具为内置Image Gen。图册是栅格视觉稿，不是运行截图、Figma组件库或可交互原型。生成模型对字段、箭头、字体和行高可能产生偏差，以下规则优先：

1. 本机网络图中右箭头和额外更多按钮删除；没有网卡详情页。地址复制保留真实操作。
2. Ping手机摘要必须换行到可读字号，结果不能挤成五列；回退开启时固定端口不适用。
3. 端口扫描手机结果按两行条目落地；图中24仅示例。
4. 关于图中的隐私政策箭头删除，直到有可用URL；Release不显示开发诊断。
