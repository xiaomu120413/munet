## 验证记录

### 最新进度：MatePad真机验收

PC追加（2026-10-22下午）：MateBook已连接，实测可缩至320vp；检查了四个页面的窄布局，发现普通鼠标滚轮不能带动横向导航，已追加Scroller滚轮映射及系统滚动条，构建成功。用户确认PC仍被其他任务占用，最后一轮PC专项返回自动化连接冲突，尚未通过。当前改动与复验入口见[PC进行中报告](ui-verification/phase5/README.md)，不得将其视为整套PC验收完成。

2026-10-22：平板宽屏三工具结果、记录表格与档案均完成实际运行比对。修复侧栏短窗口可滚动、档案宽表重复标签、特大字号标签换行；导航补选中语义。最新业务／横竖屏测试17/17通过，悬浮窗专项15/15通过（两批均含同一组14项单元测试）。CSV与JSON实际保存、清空取消、键盘菜单Esc后焦点恢复、系统朗读焦点及双击操作已检查。系统设置已恢复。证据、复现步骤和限制见[阶段4报告](ui-verification/phase4/README.md)。用户安排先平板、PC稍后，整套多端验收仍保持进行中；系统限制的悬浮窗宽度不能算作六档精确窗口全部通过。

### 最新进度：第二、三阶段首轮实现

2026-10-22：六个主页面、设备档案和手机工具入口均已迁移。端口／局域网加入原生参数选择、手机折叠设置、分行结果、宽屏表格、进度及停止／失败状态；记录加入分段、筛选、手机操作面板、宽屏独立导出菜单和清空确认；关于改为840vp以内单列阅读，Debug诊断默认折叠，Release不显示入口。各数据页的大字体宽屏阈值随系统fontSizeScale增加。

修复三工具停止后的重复启动竞态；离开任务时等待底层收尾再切页。历史导出始终走完整记录仓库，取消静默、成功才提示，清空同时处理记录和档案。默认网段异步读取不再覆盖用户已输入的网段。应用／ohosTest构建通过；MateBook执行14项测试全部通过。手机已完成回环Ping、端口扫描、单主机发现、记录与档案切换、重测回填不自动启动、系统保存器取消及清空取消检查。

证据和未通过项见[阶段2—3对照报告](ui-verification/phase2-3/README.md)。追加检查：手机首页／记录／工具／Ping／端口／关于深色截图已查看；系统超大字体下检查Ping、记录和关于，修复未启用字体跟随系统的配置，最高支持2倍。检查后恢复浅色、标准字号及默认显示缩放。电脑被其他任务占用，本批没有把被遮挡的窗口截图当成新页面验收；平板、宽屏新页面和读屏仍需设备检查。

### 第二阶段执行顺序

1. Ping：原生端口／次数Select、开关状态关联、运行锁定、手机分行／宽屏表格、可换行统计；修复解析期间重复启动与停止后迟到结果。
2. 端口扫描：范围选择、自定义校验、折叠设置、停止与部分结果、大小范围确认。
3. 局域网：CIDR输入、主机数、设备多行／表格、进度及AP隔离空态。
4. 三页一起检查主题、长文本、大小切换和运行中离开确认。每页记录实际构建／测试／截图结果，不用设计稿替代运行证据。

早期Ping批次记录：原生Select／Toggle、运行锁定、手机双行结果及宽屏表头已完成，DNS期间重复启动问题已修复，当时10/10测试通过。该批次未完成的端口、局域网和阶段3，现已继续实施，以上方最新进度为准。

2026-10-22：应用与ohosTest构建通过；MateBook真机9/9测试通过。手机模拟器验证工具入口、运行中离开确认／取消、返回后目标保留和网卡滚动；电脑验证顶部导航、双列布局和缩窗保持输入框实例及文本。亮暗资源已加入，但暗色视觉、平板真机、大字体和读屏尚未验收。
