# MuGe 包名与页面跳变修复

2026-10-23。显示名仍为木络，英文名 MuNet；包名从 `com.mu.nettools` 改为 `com.muge.munet`，vendor 为 MuGe。版本保持 0.4.0／1000004。用户明确反馈为页面闪动或布局跳变，本轮围绕布局与刷新修复。

## 修改

- 局域网、端口扫描、记录页面原以 0 宽度创建，随后 onAreaChange 才获得实际宽度。大屏每次进入会先创建窄版控件树，再切为宽版。现由外壳按实际窗口宽度减去导航栏宽度，直接传给页面；窗口改变仍会响应，切页不再等待一次测量才能选对布局。
- 记录每次进入或刷新都会把列表替换为“正在读取记录”。现仅首次成功加载前显示该占位，后续读取保留旧列表，成功后替换数据；保留加载锁，避免刷新／清空／导出并发。新增延迟仓库测试，验证刷新期间行、筛选及滚动位置保持，完成后正确替换。
- 应用配置、测试窗口定位及当前安装／启动说明均更新到新包名。历史设计稿、验收证据及旧产物不篡改，旧证据不代表新包通过同一轮验收。

## 包名与数据

新包名为独立安装身份，不会覆盖旧包。没有卸载旧应用，也没有读取或清除旧包沙箱；当前未实现跨包迁移，旧记录不会自动出现在新包。需要保留的旧记录可从旧包手动导出 CSV／JSON，当前没有导入功能。

AGC 应用、APP ID、证书／Profile、备案及后续 ACL 申请均应核对 `com.muge.munet`。没有操作开发者后台，不保证该包名可注册或已获得权限；若此前已用旧包名建立正式应用，需在后台核对新应用／资料关联方式。
