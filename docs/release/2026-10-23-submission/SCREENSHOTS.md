## 建议展示内容

下面是选题，不是官方规定的截图数量：

| 场景 | 展示内容 | 拍摄条件 |
|---|---|---|
| 本机网络 | 地址、网关、DNS、网络接口与实际可读取的Wi-Fi字段 | 自有演示网络，避免暴露真实个人SSID、MAC或第三方设备信息；没有的字段不伪造 |
| TCP探测 | 已知端口连通结果及统计 | 自有测试服务；文案明确TCP，不写ICMP或“提升网速” |
| 端口扫描 | 已授权目标的开放端口或本机地址探测 | 端口名仅常见用途提示，不宣传完整监听表或指纹识别 |
| 局域网 | 自有网段发现的设备和已解析名称 | 不为拍图扫描公共／未经授权网络；不宣传全设备或MAC识别 |
| 记录 | 重测、真实摘要、导出入口 | 使用专门的演示记录，清理仅由开发者确认；不拍用户私有目标 |
| 平板／PC布局 | 左侧导航、宽屏内容、窗口适配 | 按实际设备布局截图，标题栏隐藏，保留系统必要窗口控制；不截入其他应用 |

补拍后复核：与正式签名包同版本、中文文字清楚、无输入法／菜单遮挡关键业务、无旧校验错误、无调试信息；按实际上传校验导出，不用拼图或设计稿冒充运行画面。

审核成功案例的临时8080监听服务由ohosTest提供，Release不含测试模块，也没有内置演示服务器。不能让审核人员假定输入127.0.0.1:8080必定成功；审核指引应使用开发者可提供的自有测试环境。
