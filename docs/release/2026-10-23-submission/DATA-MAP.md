# 隐私声明与隐私标签填写依据

2026-10-23；木络／com.muge.munet／0.4.0。基于当前代码和最终验收候选整理，主体及政策URL仍待[开发者提供](OWNER-CHECKLIST.md)。

这是代码核对清单，不是已经生效的隐私政策。需开发者确认主体、联系渠道、分发地区、具体政策文本并在开发者中心配置。不能因“没有业务服务器”就直接勾选“完全不处理任何个人信息”。

| 数据／行为 | 触发时机与用途 | 当前保存／传输 |
|---|---|---|
| 网络类型、IP／前缀、网关、DNS、接口、MTU | 首页读取或用户刷新，展示本机网络状态 | 在应用内存展示；接口有地址不证明互联网可达 |
| Wi-Fi SSID、信号、频段／频率、速率 | 首页有可读取的Wi-Fi信息时 | 在内存展示；不是持续定位或位置轨迹 |
| 用户输入的目标、CIDR、探测端口 | 用户主动开始网络诊断 | 实际TCP连接到所选目标；域名会经系统解析，不能承诺完全不产生对外通信 |
| mDNS主机／服务名称、设备IP、开放端口 | 局域网发现时作名称归并 | 产生局域网服务发现通信；在线设备信息保存在设备档案，名称为尽力解析 |
| 时间、任务类型、目标、状态、结果摘要 | 每次诊断记录 | 应用沙箱`nettools.db`；扫描记录最多保留最近500条，设备档案持续保留至清空；数据库S1不是“加密存储”的对外承诺 |
| CSV／JSON | 用户选择导出及系统保存位置 | 导出当前存储的全部扫描记录，不受界面类型筛选影响；系统选择器允许的位置以系统实际支持为准，可能是用户选择的云位置 |
| 剪贴板 | 用户点复制 | 写入用户选择的地址，应用没有读取或上传剪贴板历史的功能 |
| 诊断／错误日志 | 系统生命周期、故障与导出状态 | 系统日志；Release无调试入口，启动参数的无界面调试探测不执行。不能承诺系统日志从不包含任何异常上下文 |

代码中未发现账号、广告、分析上报、应用自营后端、支付或第三方遥测SDK。运行依赖为本项目`libnettools.so`及系统Kit；hypium／hamock是测试依赖，不在Release模块中。这个结论来自源码与产物检查，不等同于第三方隐私检测报告。

应用本身不向自营服务器上传扫描历史。实际TCP／DNS／mDNS通信是用户所请求诊断的一部分；系统服务、系统备份与用户选定的云文件位置按设备和用户设置处理，未核实前不能写“数据绝不离开设备”。

用户可在记录／设备档案的更多操作中确认清空全部记录与档案；已导出文件不随应用清空，需要用户在保存位置自行管理。卸载与系统备份恢复行为应在正式签名测试中核验，当前不据调试签名覆盖安装推断。

## 尚需开发者补齐

- 运营／数据处理主体全称、联系方式、有效生效日期。
- 隐私政策公开页面或AGC托管页面，内容必须与本表及实际版本一致。
- 按AGC当前定义填隐私标签；区分设备内处理、诊断通信、历史保存与向开发者收集，不能自行发明分类。
- 儿童／未成年人、数据权利请求与投诉渠道等适用政策条款由主体确认。
- 原应用内隐私说明已依用户要求删除；本轮未恢复占位文本。正式政策有可访问入口的要求需在送审前落实，不把删除页面说明理解成无需商店隐私声明。

官方入口：[应用市场分发与隐私声明托管](https://developer.huawei.com/consumer/cn/appgallery/devstart/)、[隐私测试配置前提](https://developer.huawei.com/consumer/cn/doc/doccenter-testing/agc-help-cloudtest-faq-0000002255036920)。
