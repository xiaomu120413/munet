# 木络上架资料：com.munet.app

整理及官网核对日期：2026-10-23。当前候选1.0.0／1000000，包名com.munet.app，显示名木络，英文名MuNet，系列标识MuGe。最低API22、目标API26，声明手机、平板、PC／2in1。本轮更新版本并纳入用户新增隐私声明元数据，重新构建及验签；设备运行验收仍为此前0.4.0基线，未在本轮重跑。

**正式发布签名已完成并验证；暂不能直接送审。** 最新APP与HAP见[签名核验](../2026-10-23-v1.0.0/README.md)。复用原MuMark密钥／证书并使用木络新Profile，新生成MuNet CSR与现有证书不匹配，本次未使用新密钥。没有登录开发者中心、上传或提交审核；隐私、资质与正式包质量验证仍待补齐。

## 先办理这些

1. 按[开发者清单](OWNER-CHECKLIST.md)创建或核对新包名应用、实名认证主体及正式签名。新包名不能直接复用旧应用的Profile或APP ID关联；可复用的证书也需由后台确认，不能把证书和Profile视为同一份材料。
2. 填好清单末尾的回填表，提供真实主体、联系渠道、隐私政策页面及分发范围。证书／密钥在本机安全配置，聊天中仅提供路径。
3. 依据[权限说明](PERMISSIONS.md)办理：当前首版不用申请额外ACL；GET_IP_MAC_INFO是拟新增能力的可选申请。
4. 确认[商店文案](STORE-LISTING.md)、[数据说明](DATA-MAP.md)和[素材计划](SCREENSHOTS.md)。最终正式包再做质量与隐私验证、拍宣传图，然后提交。
