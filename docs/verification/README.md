## 读法

- 每个阶段目录的 `README.md` 写范围、环境、结论和证据边界；截图、日志、构建输出与报告放在同目录。
- 重复执行的测试不累加成“独立测试数”；报告里会写明批次和原始数量。
- 旧阶段目录中如果出现绝对路径或旧包名，属于当时环境记录；当前构建与验收命令以根目录 `README.md` 为准。
- 验证通过不等于上架就绪；签名、隐私、资质和正式包质量检查见 [发布准备](../RELEASE-READINESS.md) 与 [上架资料](../release/2026-10-23-submission/README.md)。
