## 深色模式

系统“显示和亮度→深色模式→全天开启”，标准字号。六页背景、正文、次级文字、选中态、输入、原生选择控件及按钮已查看。[六页拼图](pc-dark-contact.jpg)，原图为`pc-dark-*.png`。检查后关闭全天开启，恢复原浅色；定时开关保持关闭。

## 系统最大字号

字体滑块从原值2调到最大值5并点击应用，字重和显示大小保持原值1。最大值是系统档位，不等同于精确2倍字号。检查宽窗六页及320vp六页，原图为`pc-large-*.png`和`pc-large-320-*.png`。[宽窗拼图](pc-large-contact.jpg)

发现并修复：最窄窗口中“扫描记录／设备档案”固定横排导致省略，记录标题被操作按钮挤成逐字换行，首页标题也出现生硬断行。页头在空间不足时改为标题在上、操作在下；记录分段在字号放大且空间不足时改为上下排列，完整显示名称。正常宽度继续原布局，原生按钮、选中语义和键盘菜单保留。

修复后实机复拍[首页](pc-large-320-home.png)、[记录](pc-large-320-records.png)，已确认完整标签。最窄窗口最大字号下，鼠标滚动内容可到达完整开始按钮。[滚动后](pc-large-320-ping-scroll.png)；导航独立滚动，关于可进入。检查结束将字体恢复原值2并应用，字重／显示大小仍为1。
